# K-MMVI: 공공데이터 융합 기반 의료 이동 취약지수

> 고령층의 의료 이동 취약성을 인구·거리·의료 공급 세 차원으로 통합해 0~100점 지표로 산출한 연구

| --- | --- |
| 기간 | 2026.05 – 2026.06 |
| 형태 | 2인 공동 연구 (신현진 · 김병재, 한신대학교) |
| 분석 단위 | 전국 250개 시군구 |
| 사용 기술 | Python, Git |

## 문제 정의

65세 이상 인구가 20%를 넘었지만 상급종합병원은 수도권과 광역시에 몰려 있어, 지방 고령층은 병원까지 가는 것 자체가 어렵습니다. 기존 분석은 병원 수·의사 수 같은 공급 지표에 의존해 **고령층의 실제 이동 제약**을 반영하지 못하고, 데이터도 기관별로 흩어져 있었습니다.

## 데이터

행정안전부 · 보건복지부 · 국립중앙의료원 공공데이터 (2023년 기준)

| 변수 | 의미 |
| --- | --- |
| X₁ 인구 위험성 | 65세 이상 고령인구 집중도 |
| X₂ 의료 원격성 | 최근접 종합병원까지의 물리적 거리 |
| X₃ 의료 공급 밀도 | 면적 대비 의료 공급 인프라 |

## 방법: 5단계 분석 프레임워크

1. **데이터 통합**: 시군구 코드 기준 Spatial Join (EPSG:5179)
2. **정규화**: Min-Max 0~1 스케일, 의료기관 밀도는 역방향 처리
3. **가중치 산출**: 엔트로피 가중치법으로 연구자 주관 배제
4. **스코어링**: `K-MMVI = Σ (Wj × X′j)` + 물리적 차단 플래그
5. **검증**: 헬스맵 응급취약지와 비교 (F1, AUC), 읍면동 단위 미시 분석

**엔트로피 가중치**: 거리 0.746 · 고령인구 0.230 · 의료기관 밀도 0.025

**물리적 차단 선제 플래그**: `관내 종합병원 수 = 0 AND 최근접 병원 거리 > Dthr`이면 복합 점수와 관계없이 최우선 취약지로 분류합니다. 다른 지표가 양호해서 극단적 의료 공백이 가려지는 상쇄 효과를 막기 위한 규칙입니다.

## 결과

- 전국 평균 18.81점 (최소 2.66 · 최대 89.65)
- 취약 지역은 경북 북동부, 전남 도서, 강원 산간에 집중

| 지표 | 값 |
| --- | --- |
| AUC | 0.959 |
| F1-Score | 0.892 |
| 정확도 | 0.912 |
| 점이연 상관 | 0.783 |

- 상위 10개 지역 **전부** 헬스맵 응급취약지와 일치
- 물리적 차단 플래그로 **33개** 시군구 식별
- 헬스맵이 포착하지 못한 잠재 취약지 **11곳** 추가 발굴

## 내 역할

- **물리적 차단 선제 플래그** 알고리즘 설계
- 정규화한 3개 변수의 가중합산으로 **K-MMVI 점수 산출**
- **엔트로피 가중치** 기반 객관적 가중치 적용

## 정책적 활용

- 수요응답형 교통(DRT) 노선 배치 우선순위 결정
- 이동 진료차·방문 보건 인력 우선 파견 지역 선정
